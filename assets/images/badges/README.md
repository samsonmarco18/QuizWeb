# Achievement artwork

`achievement-atlas.png` was generated with the built-in image generation tool for CHALK. Its transparent 2?2 grid is consumed directly with CSS background positions; no image edits were performed.

Prompt:

Use case: stylized-concept. Asset type: one cohesive achievement badge sprite atlas for the CHALK student portal. Create a transparent square canvas divided into an exact 2 by 2 grid, four equal square cells. Each cell contains one centered small polished enamel achievement medal with generous equal transparent padding, readable at 64 pixels. Top left: teal shield with a mint check mark, first assessment. Top right: gold hexagonal medal with an open book and small star, mastery. Bottom left: turquoise circular medal with an upward arrow, improvement. Bottom right: lavender shield with a lightning bolt, practice dedication. Match a restrained dark teal educational interface, mint accents, subtle bevels and soft highlights, clean silhouettes. No text, no letters, no numbers, no background, no floating decorations, no shadows outside each medal. All four medals equal visual scale.
